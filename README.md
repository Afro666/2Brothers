# Junction 2026

Team: Aron, Tymon, Maciek.

Idea: a purchasing agent that Valio Aimo gives to its kitchen customers. It predicts what a
kitchen needs, orders within the kitchen's mandate, asks a human for the rest, and logs every
step. With consent, Valio sees the predicted demand across customers. Challenge: Valio Aimo
Trusted Trade Agents. Plan: [`docs/plan.md`](docs/plan.md). Why it is built this way:
[`docs/choices.md`](docs/choices.md). Live API docs: `/api/docs` on the demo site.

## Start

1. Clone the repo.
2. Copy `.env.example` to `.env` and fill in the keys.
3. Read `CLAUDE.md` (team rules for people and agents).

All Junction challenges: see [`challenges.md`](challenges.md).

Every change is a PR reviewed by Opus (see [`CLAUDE.md`](CLAUDE.md)).
