SAY: The rule behind everything you saw. The model picks the products. Code sets every quantity and every total. A person approves the exact total. And code refuses three things: an agent approving its own order, a price that moved, and peanuts in a peanut-free kitchen. TO VALIO, ADD: This is the guardrails model you asked for. Today the agent decides nothing alone. Auto-approve exists and is off: a kitchen has to earn it with four weeks and twenty of its own decisions. TO NVIDIA, ADD: Nemotron gets a numbered shortlist and answers in a strict JSON schema. A pick outside the shortlist is refused, and so is a reason with a number that is not in the data. TO MONGODB, ADD: One yes covers exactly one order: a unique index in Atlas returns the stored order when the same request comes twice.
