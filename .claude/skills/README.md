# Skills for Claude sessions in this repo

Four skills from [emilkowalski/skills](https://github.com/emilkowalski/skills)
(MIT, licence in `LICENSE-emilkowalski-skills`), copied at commit `0f2e23b`
on 2026-11-13:

| Skill | Use it for |
|---|---|
| `emil-design-eng` | Polish of a component's interactions: press and hover states, easing, timing. Includes `ui-cheatsheet.md`. |
| `break-ui` | Worst-case data on a screen: long product names, empty lists, huge counts. |
| `mobile-native` | Making the web app feel right on a phone. |
| `ask-sonner` | Toasts with Sonner. |

The component kit in `web/` stays the design guide (components, tokens, the
"unknown is never zero" rules). These skills are for the polish and testing
pass on top of it.

One change from the source: a last line in `emil-design-eng/SKILL.md` points
to the cheatsheet. That skill also mentions a `choreograph` skill, which is
not installed here.
